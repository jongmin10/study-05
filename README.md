# PDF AI 요약기

PDF 문서를 업로드하면 AI가 한국어로 요약해주는 웹 애플리케이션입니다.
별도 설치나 서버 없이 `index_pdf.html` 파일을 브라우저에서 바로 실행할 수 있습니다.

## 주요 기능

- 드래그&드롭 또는 클릭으로 PDF 파일 업로드
- PDF.js 기반 텍스트 추출 (페이지별 진행 상태 표시)
- OpenRouter API를 통한 AI 요약 (무료 모델 사용)
- 핵심 주제 / 주요 내용 / 결론 구조로 한국어 요약
- 요약 결과 클립보드 복사

## 사용 방법

1. [OpenRouter](https://openrouter.ai)에서 무료 API 키 발급 (`sk-or-` 로 시작)
2. `index_pdf.html`을 브라우저에서 열기
3. API 키 입력 후 **저장** 클릭
4. PDF 파일 업로드 후 **AI 요약 시작** 클릭

## 제한 사항

- 텍스트 레이어가 있는 PDF만 지원 (이미지 스캔본 불가)
- 파일 크기 최대 20MB
- 추출 텍스트 12,000자 초과 시 자동 잘림

## 기술 스택

| 항목 | 내용 |
|------|------|
| 구현 방식 | 단일 HTML 파일 (서버 불필요) |
| PDF 처리 | [PDF.js](https://mozilla.github.io/pdf.js/) 3.11.174 |
| AI 모델 | OpenRouter `openrouter/free` (무료 모델 자동 선택) |
| 인터페이스 | 한국어 |
